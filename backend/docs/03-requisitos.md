# 3. Requisitos

## Funcionais iniciais

RF01 — Cadastrar jogador.
RF02 — Criar partida.
RF03 — Exibir próximo jogo.
RF04 — Confirmar presença.
RF05 — Registrar ausência.
RF06 — Listar jogadores.
RF07 — Registrar pagamentos.
RF08 — Exibir avisos.
RF09 — Permitir administração do grupo.
RF10 — Consultar histórico de partidas.

## Não funcionais iniciais

RNF01 — Interface responsiva para celular.
RNF02 — Botões grandes e fáceis de identificar.
RNF03 — Navegação simples.
RNF04 — Feedback visual após ações.
RNF05 — Compatibilidade com leitores de tela sempre que possível.
RNF06 — Contraste e foco de teclado adequados.
RNF07 — Proteção de dados dos usuários.
RNF08 — Sistema com desempenho adequado para o grupo.

Observação: os requisitos devem ser revisados após o levantamento presencial com os usuários.
