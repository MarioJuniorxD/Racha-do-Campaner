# 1. Projeto

## Nome
Futebol da Empresa — Sistema colaborativo para gestão de patota de futebol com suporte de acessibilidade.

## Público
Grupo real de colaboradores que participa de partidas de futebol.

## Problema inicial identificado
Os participantes apresentam dificuldades no uso de celular e na organização das informações relacionadas às partidas.

## Objetivo
Criar uma solução simples, colaborativa e acessível para organizar jogos, presença, jogadores, pagamentos e avisos.

## Base da atividade
A atividade extensionista propõe uma solução colaborativa para gestão de patota de futebol, com foco em comunicação, cooperação, coordenação, usabilidade e acessibilidade.
