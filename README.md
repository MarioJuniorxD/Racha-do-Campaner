# Futebol da Empresa

Sistema colaborativo para gestão de um grupo de futebol, desenvolvido como atividade extensionista.

## Objetivo
Facilitar a organização das partidas, presença dos jogadores, comunicação, pagamentos e informações do grupo, com foco em simplicidade, usabilidade e acessibilidade.

## Stack inicial
- Frontend: HTML5, CSS3 e JavaScript
- Backend: Node.js + Express
- Banco: SQLite
- Protótipo: Figma (opcional)
- UML: draw.io / PlantUML (opcional)

## Estrutura
- frontend/: interface do usuário
- backend/: API e regras de negócio
- database/: banco e scripts
- docs/: requisitos, personas, UML e documentação acadêmica
- tests/: testes

## Como começar
1. Instale Node.js LTS.
2. Entre em `backend`.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra `http://localhost:3000`.

A versão inicial é um esqueleto funcional. As funcionalidades serão implementadas gradualmente e validadas com os usuários.
